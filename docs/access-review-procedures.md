# Access Review Procedures — Regional Health Clinic

## Purpose
To ensure access rights stay aligned with job roles and least-privilege principles over time, access must be reviewed on a regular basis and whenever a role changes.

## Review Triggers
- **Scheduled review**: Quarterly review of all role-based access assignments across departments.
- **Role change**: Any promotion, transfer, or change in job duties triggers an immediate access review for that individual.
- **Termination**: Access is revoked immediately upon employee termination or resignation.
- **New hire**: Access is granted only after role assignment is confirmed, following the standard role-based permissions for that position.

## Review Process
1. **Identify current access** — pull a report of all active accounts and their assigned permissions per department.
2. **Compare against role matrix** — check each account against the documented role-access matrix to confirm access matches the defined role.
3. **Flag discrepancies** — any account with access beyond what its role matrix defines is flagged for review (over-provisioned access).
4. **Remediate** — excess access is removed; missing necessary access is granted, following manager/IT approval.
5. **Document** — each review cycle is logged with date, reviewer, and any changes made, for audit purposes.
